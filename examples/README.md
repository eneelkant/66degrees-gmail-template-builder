# 📦 Examples

Four ready-to-paste 66degrees templates, built the way the editor likes them: one table row per section, inline styles, Arial, real text and pictures from the image library.

| Template | What's in it |
|---|---|
| [`templates/event-invitation.html`](templates/event-invitation.html) | Team photo, "You're invited", details box, Reserve my seat button, agenda |
| [`templates/newsletter.html`](templates/newsletter.html) | Monthly Pulse header, top story with photo, two columns, shout-out box, button |
| [`templates/hr-update.html`](templates/hr-update.html) | Blue deadline band, message, key dates, Review my benefits button, questions |
| [`templates/announcement.html`](templates/announcement.html) | Title, photo, message, quote, numbered "what this means for you", sign-off |

To use one: **New template → Open editor → Paste HTML**, paste the file, **Save and check**. The pictures point to `your-image-bucket`; swap them with **Edit in preview → Upload** or **From library**.

## 🪄 A prompt that gives great email code

Whatever the design is made in (Figma, Canva, a screenshot), give it to Gemini, ChatGPT or Claude with:

> Turn this design into an HTML email for Gmail. Use tables for layout (one table row per section), inline CSS, a 600px width, Arial or another web-safe font, and real text (not text inside images). No JavaScript, no external CSS files. Use the 66degrees colours: Night Blue #040A1B, 66° Blue #0052FF and Shark Grey #B3C5D0.

Then upload the real photos and logos with **Edit in preview → Upload**. A screenshot gives the AI the layout, not the image files.
